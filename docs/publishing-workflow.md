# 發布工作流程

## 單位最新消息

```text
單位編輯者建立草稿
→ 單位管理員確認
→ 單位管理員發布
```

單位編輯者可預覽並送出確認，但不能發布。單位管理員只可發布自己單位消息。消息截止後改為 `expired`，不再顯示在首頁但仍可於歷史消息查閱；不直接刪除。

## 跨單位或全站內容

```text
單位提供資料
→ 醫學研究部總管理員整合
→ 發布
```

跨單位消息只建立一筆，以 `owner_unit_id` 指定主要負責單位，以 `related_unit_ids` 指定共同顯示單位。主站推薦不複製內容，只建立推薦關係。

## 單位正式介紹

單位正式介紹由該單位自行撰寫、確認及發布，不固定經過醫學研究部審核。醫學研究部總管理員可在緊急情況協助下架錯誤內容或回復版本。單位名稱、網址代碼、隸屬、啟用、排序與版型仍是結構性資料，另依權限維護。

## 正式系統必要控制

- 後端權限驗證與工作階段。
- 發布前的欄位驗證、時間與顯示範圍檢查。
- 版本紀錄、差異比較與回復。
- 不可竄改的操作紀錄。
- 代理、緊急下架、到期轉換與通知規則。
