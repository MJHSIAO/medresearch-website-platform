# 瀏覽與文件下載統計

版本 2026.11.13.1 起，管理中心左側「工作台」下方新增「瀏覽統計」。工作台顯示今日及近 30 日瀏覽摘要；專頁可選近 7／30 天及單位，查看期間瀏覽次數、每日平均、文件下載、趨勢、每日數值及三種熱門內容排行。

## 計數口徑

- 瀏覽次數是有效公開頁面的成功 GET 請求（HTTP 200，或靜態頁快取重新驗證的 304），不是不重複訪客數。重新整理可重複計算；HTML 成功回應不代表所有圖片與 JavaScript 均已載入或使用者讀完內容。
- 頁面包含醫研部首頁、消息列表、隸屬單位、搜尋、聯絡頁、公開一般內容頁、有效單位首頁／介紹、公開消息詳細頁及本站保留的 AI 子站內頁。無效 ID、非公開／未啟用單位及未發布內容不計。消息歷史列表中的已過期公開消息仍可計數。
- 首頁 `/` 與 `index.html` 共用一筆；單位 slug／ID 使用同一單位識別碼；主站及 AI 子站開啟相同消息均歸入同一消息。搜尋字詞、任意 query、UTM 與錨點不儲存、不建立額外統計項目。
- 瀏覽總數包含「頁面瀏覽」及「消息瀏覽」，兩種排行榜分列。消息以主要負責單位歸屬，不因 related_unit_ids 或在主站推薦而重複建檔。
- 文件公開清單的「下載」連到 `/api/documents/{id}/download`，後端重新驗證目前發布狀態、主要單位及實際檔案，成功回應才記一筆下載事件。預覽、另開檢視、直接素材／media 網址、外部網站下載不計；下載事件不等同完整傳輸完成，也不加進頁面瀏覽總數。草稿／下架文件回傳 404；歷史下載統計保留。
- 排除已登入的三種管理角色在公開頁及下載入口的操作；一般院內登入者瀏覽公開頁仍可計數。管理中心、院內專區、API／JSON、圖片／腳本、HEAD、錯誤回應、嵌入預覽、預先載入與可辨識爬蟲不計。只依請求標頭辨識，不保證排除所有機器流量，也不是防灌票系統。
- 日期以 Asia/Taipei（UTC+8）分日，包含今日目前累計。沒有紀錄時顯示 0 與空清單。首次記錄之前不繪製趨勢點，每日數值顯示「未開始記錄」；平均以所選範圍內、該統計範圍首次記錄起的日數計算，包含今日。新版部署前的流量無法追溯。

## 權限與保存

`GET /api/manage/analytics?days=30&unit=` 沿用登入管理 API 的後端授權，每次請求重新解析角色與單位。單位管理員的空白 unit 代表全部授權單位；指定其他單位或醫研部主站回傳 403。醫研部總管理員及系統管理員可查看全站及個別單位。匿名回傳 401，一般院內人員回傳 403；前端篩選不代替授權。

統計保存於既有私有 `DATA_DIRECTORY/analytics/YYYY-MM-DD.json`，每日只保存內容識別碼、當時公開標題、主要單位、標準內容路徑及次數。不保存訪客 IP、帳號、Cookie、User-Agent、搜尋字詞或完整查詢網址；不使用外部分析服務、額外追蹤 Cookie、localStorage 或資料庫。

每日檔案沿用單程序鎖、暫存檔 fsync 與原子替換，與內容 state.json 分開，瀏覽不改寫消息、授權、版本或稽核。維持一個 worker／一個容器實例，不支援多程序共寫。每日統計持續保留，不提供後台刪除／重設入口；備份及還原須涵蓋整個既有資料卷。Git 更新及重建容器不會清空資料卷。

統計寫入失敗會記固定的應用程式錯誤日誌，不阻斷公開網站；可能漏計，應由維運檢查磁碟／權限。讀取損壞資料時 API 回傳 503，介面顯示失敗與重試，不以假數字代替或重設檔案。從工作台無法讀取統計時，仍可正常管理內容。

## 上線與驗證

Git 推送不等於上線。依 [部署驗證](deployment-verification.md) 重建既有 `medresearch-app`，保留環境檔與 `medresearch-data`。`/api/version` 應為 `2026.11.13.1`。以未登入的瀏覽器開啟公開頁、從文件清單下載，再以管理員進入統計按「更新統計」核對；管理員自己的公開頁瀏覽不計數。請勿把本機隔離測試數字複製到正式資料卷。

離線檢查：`python -m tests.check_analytics`。涵蓋真實 API 請求、單位隔離、撤權、公開過濾、排除條件、標準識別碼、文件下載與預覽分流、原子保存、並行計數、臺北跨日、檔案損壞及 `/medresearch/` 子路徑。實際執行結果見 [驗收紀錄](phase-1-acceptance.md)。
