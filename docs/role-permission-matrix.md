# 角色與權限矩陣

2026-11-23：新增「醫學研究部（本部）」可授權範圍，沿用 `unit_admin`，只管理本部；與可跨單位的 `site_admin`（醫研部總管理員）不同，不新增高階角色。詳見 [本部整合](department-integration.md)。

## 正式版角色決策（2026-10-16）

單位不再區分編輯者與管理員。同一單位可有多位管理員，均可編輯與發布被授權單位的內容。系統管理員擁有全部功能，不需要兼任醫研部總管理員。

| 功能 | 單位管理員 | 醫研部總管理員 | 系統管理員 |
| --- | --- | --- | --- |
| 文件表單新增／上傳／發布／下架 | 授權單位 | 全部單位 | 全部單位 |
| 編輯、發布與下架內容 | 授權單位 | 全部單位 | 全部單位 |
| 成員排序／刪除及刪除時連動移除該單位管理授權 | 授權單位；不動全站角色 | 全部單位；不動全站角色 | 全部單位；不自動撤銷全站角色 |
| 設定成員與帳號的明確關聯 | 否 | 已有授權帳號 | 已有授權帳號 |
| 移除人員管理授權 | 否（僅上述成員刪除的同單位連動） | 單位管理員的指定單位 | 指定範圍；保護伺服器保留及最後系統管理員 |
| 管理醫研部首頁及單位排序 | 否 | 是 | 是 |
| 查看／回復歷史版本 | 授權單位 | 全站 | 全站 |
| 新增、調整或停用單位管理員授權 | 否 | 是 | 是 |
| 任命醫研部總管理員或系統管理員 | 否 | 否 | 是 |
| 修改共用版型與系統設定 | 否 | 否 | 是 |
| 查看操作紀錄 | 授權單位 | 全站 | 全站 |
| 查看瀏覽與文件下載統計 | 授權單位 | 全站／單位篩選 | 全站／單位篩選 |

一般院內人員沒有管理角色。院內登入不等於取得管理權限。醫研部總管理員不得變更高階管理者的角色或停權；正式 API 須驗證操作者及被管理者的權限範圍。

## 結構性欄位

單位正式名稱、網址代碼、隸屬關係、啟用狀態、排序與全站導覽由醫研部總管理員或系統管理員維護；共用版型與系統設定僅由系統管理員維護。

## 目前實作狀態（2026-10-22）

以上角色由後端每次請求重新解析，內容與授權保存於私有 JSON 儲存區。管理頁依身分顯示功能，API 同時驗證單位範圍；不使用 localStorage 或角色選單授權。系統管理員共用外觀設定支援主色與容器寬度；部署金鑰仍由伺服器環境維護。

詳見 [正式管理指南](management-guide.md)。

2026-11-18：單位文件與表單、共用檔案庫及單位摘要沿用相同角色範圍。單一單位管理員新增文件／上傳可由後端自動取其唯一授權單位；多單位須選擇獲授權的單位。一般院內人員只能讀取已發布院內文件，不能管理。對外公開 API 不回傳院內文件。共用檔案選用亦由後端依單位過濾與驗證。
