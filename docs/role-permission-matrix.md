## 結構性欄位

單位正式名稱、網址代碼、隸屬關係、啟用狀態、排序、全站導覽位置及共用版型，不開放一般單位編輯者或管理員修改。這些欄位由醫研部總管理員或系統管理員依職責維護。

## Demo 與正式系統的差異

本版依 localStorage 中的示意角色切換畫面與按鈕，但這不是安全機制。正式系統必須：

1. 由後端建立登入工作階段並解析角色及單位範圍。
2. 每次查詢與寫入都在後端驗證權限，不能只依前端隱藏按鈕。
3. 由後端自動設定 `owner_unit_id`，一般使用者不得指定。
4. 將操作紀錄寫入不可由一般使用者竄改的正式儲存層。
5. 驗證代理、停權、離職與緊急處置流程。
