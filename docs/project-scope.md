# 專案範圍

## 定位

本平台是醫學研究部及七個隸屬單位的共用網站基礎。六個單位使用共用版型；人工智慧中心使用先前完成的第一版獨立多頁子站。所有單位仍以單一資料來源維護基本資料。

## 第一版交付

- 公開網站：首頁、最新消息列表／詳細頁、隸屬單位列表、單位首頁／完整介紹、一般內容頁及聯絡資訊頁。
- 多單位資料：七個官方隸屬單位、公開消息、研究服務、一般頁面、人員與媒體 JSON。
- 行政後台 UI Demo：角色切換、單位資料、消息列表／編輯、媒體預覽、操作紀錄。
- 響應式與無障礙基礎：桌機、平板、手機、鍵盤、focus、跳至內容、表單 label、替代文字及對比。
- 完整專案文件與驗收依據。

## 明確排除

不實作正式登入、Active Directory、Microsoft Entra ID、CMS、資料庫、API、後端權限、正式上傳、寄信、病人資料或院內機密。`localStorage` 與角色切換僅模擬操作流程。

## 外部專案邊界

原人工智慧中心專案維持唯讀，不構成本平台的執行時依賴，也不使用 iframe 或 Git submodule。本平台僅將其公開網站第一版必要檔案複製至 `ai-center/`，並改由本平台共用的 `data/units.json` 與 `data/news.json` 同步基本資料與公開消息。

## 內容可信度

公開內容依醫學研究部原官網整理並保留官方來源連結，資料查核日期為 2026-09-01。正式規章、表單版本、聯絡資訊與後續異動仍以原官網為準；未公開或無法確認的資料不以推測內容補入。
