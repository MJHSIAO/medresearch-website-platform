# 行政後台 Demo 操作指南

## 開啟方式

由本機 HTTP 伺服器開啟 `/admin-demo/`。畫面頂端及角色切換區均標示「此為 UI Demo，不代表正式權限驗證」。

## 建議展示流程

1. 以「人工智慧中心編輯者」開啟後台，確認只看到自己單位的內容功能，消息表單沒有發布按鈕。
2. 進入「修改單位介紹」，修改簡短／完整介紹並儲存。
3. 開啟單位網站預覽，確認卡片、單位首頁與完整介紹從同一筆資料同步更新。
4. 新增最新消息，先儲存草稿，再送出確認。
5. 切換「人工智慧中心管理員」，確認可看到發布按鈕，但看不到其他單位編輯入口或全站設定。
6. 切換「醫學研究部總管理員」，確認可看到所有單位、首頁管理、消息推薦與全站操作紀錄示意。
7. 切換「系統管理員」，確認畫面改為版型、帳號角色、系統設定及操作紀錄示意，不呈現一般內容編輯入口。
8. 選擇圖片或附件，確認僅顯示瀏覽器端預覽及安全提醒。
9. 按「重設示意資料」清除 Demo 修改。

## localStorage 說明

`localStorage` 只供 UI Demo 使用，不是正式資料庫或權限系統。資料只存在目前瀏覽器，可被使用者自行修改或清除；不可作為正式發布、稽核或身分驗證依據。

使用的 key：

- `medresearch_demo_role`：示意角色。
- `medresearch_demo_unit_{id}`：單位資料覆寫。
- `medresearch_demo_news`：新增或編輯的消息。
- `medresearch_demo_audit`：示意操作紀錄。

## 圖片與附件

Demo 使用 `FileReader` 建立本機預覽，不會傳送檔案。畫面顯示建議比例、格式、5 MB 示意上限、替代文字與禁止上傳病人資料／個資提醒。正式系統仍需後端驗證格式、大小、掃毒、存取權限及留存政策。
