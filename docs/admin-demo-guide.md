# 既有後台功能預覽操作指南

## 開啟方式

由本機 HTTP 伺服器開啟 `/admin-demo/`。畫面頂端標示「管理功能建置中 · 尚未啟用正式授權」，功能視角只供本機預覽。網址為相容既有連結暫時保留，不表示已完成正式版。

## 本機預覽流程

1. 以單位管理員視角開啟後台，確認只看到自己的單位內容。
2. 修改單位介紹並儲存，確認公開預覽同步使用本機覆寫資料。
3. 建立消息草稿或儲存發布預覽；不需要編輯者送審，且不會正式發布。
4. 切換醫研部總管理員，確認跨單位管理入口。
5. 切換系統管理員，確認所有內容、醫研部與系統功能入口均可見；系統設定與帳號任命尚未啟用。
6. 圖片附件僅供本機預覽；選擇「清除本機預覽資料」可清除此瀏覽器的修改。

## localStorage 說明

`localStorage` 只供 UI Demo 使用，不是正式資料庫或權限系統。資料只存在目前瀏覽器，可被使用者自行修改或清除；不可作為正式發布、稽核或身分驗證依據。

使用的 key：

- `medresearch_demo_role`：示意角色。
- `medresearch_demo_unit_{id}`：單位資料覆寫。
- `medresearch_demo_news`：新增或編輯的消息。
- `medresearch_demo_audit`：示意操作紀錄。

## 圖片與附件

Demo 使用 `FileReader` 建立本機預覽，不會傳送檔案。畫面顯示建議比例、格式、5 MB 示意上限、替代文字與禁止上傳病人資料／個資提醒。正式系統仍需後端驗證格式、大小、掃毒、存取權限及留存政策。
