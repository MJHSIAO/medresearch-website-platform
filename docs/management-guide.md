## 2026-11-18 成員排序與授權移除

「單位成員」先選單位，可拖曳把手或按上下移，再按「儲存順序」，前台與重新整理同步。刪除前顯示姓名及影響範圍，只移除該單位成員；有明確帳號關聯時，一併移除必要的該單位管理授權，不影響其他單位或院方帳號。

「人員權限」依單位分組、原有角色及姓名／識別值排序，多單位人員分列；刪除只撤銷所選列範圍，保留公開成員與內容。伺服器保留管理員及最後一位系統管理員仍受保護。高階管理員可於成員表單選填明確帳號關聯，不以同名推測。操作、保存及預覽限制見 [成員與授權管理](personnel-management.md)。

## 初次授權

院方登入識別欄位已確認為 `sub`。維運人員於伺服器設定 `ADMIN_IDENTITY_CLAIM=sub`，並將第一位系統管理員實際回傳的 sub 填入 `SYSTEM_ADMIN_IDS`，重建容器後重新登入。真實名單不提交 Git。身分確認表格已關閉，院內專區只提供一般功能。

操作紀錄可顯示「姓名（員編）」：由伺服器 `OIDC_NAME_CLAIM` 指定已確認的 OAuth 姓名欄位，新操作保存當時姓名；未設定／無姓名及舊紀錄維持原員編，不回填猜測姓名。查閱範圍與授權規則不變。院方 `unique_name` 已確認存在，實際值仍待驗證，範例設定暫留空；詳見 [姓名確認及設定](login-authorization.md)。

## 新增或停用人員

從院內專區進入管理中心，選「人員權限」→「新增授權」，輸入與院方欄位完全相同的識別值（若已確認該欄位為員編，即填員編），選角色。單位管理員需勾選一個以上單位。按「儲存授權」後生效；對方不需要先登入，之後登入取得相同識別值即套用授權。

既有授權選「調整／停用」，取消啟用可立即撤權。醫研部總管理員只能管理單位管理員；只有系統管理員能任命或停用高階角色。伺服器保留管理員只能由環境設定調整。沒有前端角色切換。

## 維護網站

「跑馬燈公告」由系統管理員及醫研部總管理員管理，單位管理員不可存取。可新增、編輯、刪除、啟用或停用，每則 1–200 字，可選填站內相對路徑或 HTTP／HTTPS 連結；新增公告排在最前方。停用公告只留在後台，刪除前須確認。寫入使用既有 CSRF、來源驗證、版本衝突控制及私有持久化資料卷，並保存歷史與操作紀錄。

原先網站頂端公告會作為第一則內容保留，不需手動搬移。明確刪除或停用後不會因重新啟動而恢復舊公告；全數移除後只保留右側帳號資訊。日後請使用「跑馬燈公告」維護，不再從網站資訊表單修改舊 notice 欄位。

前台公告與帳號資訊共用一列。跑馬燈自動捲動，滑鼠移入及鍵盤聚焦時停止，移開／離開後繼續；沒有播放或暫停按鈕。系統設定減少動畫時改為靜態可捲動文字。前台重新載入、回到分頁或最長約 30 秒會取得更新；網路失敗時保留已顯示的內容。

共用頁首使用院方官網公開的正式 Logo，原始來源為 https://www.femh.org.tw/images/template/logo_g.svg ，檔案為 assets/images/femh-logo-official.svg；保留原比例與顏色，不需於每次載入時連線院方官網下載。院名旁以分隔線搭配醫學研究部名稱。

管理中心採左側功能選單與工作台。左下顯示目前登入者的實際角色與授權單位，不提供角色切換；單位管理員只顯示獲授權單位，系統管理員可管理全部功能。工作台數量、最新消息與操作紀錄均讀取伺服器。手機以左上選單按鈕開啟功能，表格可橫向捲動。

公開網站的「院內人員登入」位於導覽上方獨立列的右側。登入後顯示院方驗證的識別碼與姓名；相同值只顯示一次，院方未提供姓名時保留識別碼，不推測或寫死姓名。一般院內人員另顯示登出；單位管理員、醫研部總管理員與系統管理員顯示相鄰的「院內專區」與「管理中心」，可直接進入管理中心。登入後返回原頁面，不再依角色自動進入院內專區或管理中心。功能入口依伺服器驗證後的角色判斷，隱藏連結不取代後端權限驗證。桌機公告移動範圍以 600px 為上限，在公告可用空間內置中，與右側帳號保持間距；手機依可用寬度縮小，登入身分可換行。

首頁最新動態顯示發布日期最新的三則公開消息；「首頁推薦」不再將較舊消息排到新消息之前。草稿、待確認、下架、僅院內與過期消息不列入首頁。截止日或公開範圍不符時，即使消息存在管理中心，也不會出現在首頁。

「檔案與附件」列出目前角色可管理的實際伺服器上傳檔，顯示名稱、所屬單位與大小，可選單位後上傳。新版上傳會保存原檔名；舊檔優先使用消息附件名稱，無名稱則顯示原識別碼。此列表不包含初始靜態素材，也不自動刪除未引用檔案；消息仍可在表單內直接上傳並建立附件關聯。

- 單位資料：編輯介紹、宗旨、業務、目標及聯絡資訊；高階管理員可調整排序與進階結構欄位。
- 單位成員：新增或編輯公開成員，姓名、職稱及簡介由表單維護；成員摘要同步更新。
- 消息與發布：填標題、摘要與本文，分類使用選單；所屬單位由授權範圍選擇，既有消息不可自行移轉單位。按「儲存草稿」保存到伺服器，按「發布」才公開；已發布消息提供「發布更新」、「轉為草稿（停止公開）」及「下架」。顯示範圍及首頁推薦收在其他發布設定。

- 消息圖片與附件：直接在消息表單選檔上傳、預覽及移除，不需手填路徑。獨立「檔案與附件」入口可查看授權範圍內的伺服器檔案。只接受 PNG、JPEG、PDF，每個檔案 5 MB 上限。

## 儲存與維運界線

「瀏覽統計」位於左側工作台下方，可選近 7／30 天及授權單位，查看摘要、每日趨勢、每日數值及頁面／消息／文件下載排行。工作台另顯示今日與近 30 日瀏覽。數字來自伺服器，部署後開始累積；管理員自身瀏覽及文件預覽排除。統計的首次記錄日期、平均日數、保存及權限詳見 [瀏覽與文件下載統計](analytics.md)。

本版維持 JSON 儲存及單一程序架構，鎖定交易、原子替換與版本衝突控制避免同程序寫入互相覆蓋。禁止多 worker 或多實例共寫；重啟會清除登入 Session，但不清除正式內容及授權。

備份整個 DATA_DIRECTORY，還原前停止服務。正式資料卷不隨 Git 更新清空，不執行帶 `-v` 的 Compose down。磁碟權限與備份由維運管理。操作紀錄沒有對外刪除 API，但擁有磁碟權限者仍能修改；不宣稱不可竄改稽核。上傳檢查大小與檔頭，不等同防毒掃描。

寄信、外部防毒與多實例 Session Store 未在本次交付，線上洽詢維持停用。正式環境的院方登入回傳欄位及第一位管理員設定，仍須由維運確認。


## 將舊消息搬到伺服器

正式管理中心 `/admin` 的新增、儲存及發布都透過受保護 API 寫入私有 `DATA_DIRECTORY/state.json`；沒有 localStorage 寫入或離線保存。失敗會顯示錯誤，不會退回本機儲存。

舊版在瀏覽器保存的消息需另行匯入。在原本發布的電腦、瀏覽器及設定檔登入正式管理中心，選「匯入舊消息」→「預覽並匯入」→核對所屬單位→「匯入為伺服器草稿」。匯入只讀取原有 `medresearch_demo_news`，不修改或清除瀏覽器資料。

匯入保留原消息 ID 與日期，因此發布後原 news-detail 網址可繼續使用。匯入不會直接發布，請在消息編輯頁核對本文、顯示範圍及附件後發布。伺服器已有同 ID 時拒絕覆蓋；每次匯入仍驗證登入、CSRF 與單位權限。圖片／附件若當時只有瀏覽器預覽，需重新上傳。

換電腦、無痕模式或清除舊網站資料後，可能無法找到原消息。此時須由原瀏覽器備份或維運備份取回；僅憑標題或 URL 無法重建原文。只有原文已匯入並經伺服器儲存，才算完成復原。


## 簡化消息表單（2026-11-02）

新增／編輯消息改用專用表單，沒有圖片路徑手填欄位或進階 JSON。必填標題、摘要、本文，其餘以選擇或預設值處理；舊分類會保留在選單中。

發布、截止及活動日期均使用日曆。發布日期預設今天，未自行指定時以實際發布時間保存；截止日可留空。既有日期未改動時保留原時間及時區精度。日期是顯示資料，不提供預約發布。

消息表單直接多選 PNG、JPEG、PDF 上傳，每個檔案最多 5 MB；成功後顯示檔名、檢視連結，圖片可預覽。選檔即上傳至私有儲存區，儲存消息後才建立附件關聯；未發布內容不會公開附件。可從表單移除附件，儲存後生效；不會刪除伺服器檔案或其他消息的引用。

封面／列表預覽圖片選填，可從已上傳圖片按「用作列表預覽」設定，亦可選擇不使用。只有選擇預覽圖才顯示圖片說明；可提供簡短替代文字，未填時使用標題作基本說明。沒有封面仍可發布；PDF 不產生第一頁縮圖。

編輯及歷史回復會保留未變更的原始欄位、相關圖片、附件、分類與日期。已發布內容按「轉為草稿（停止公開）」會停止公開；若要更新公開內容，請按「發布更新」。保存失敗不寫入 localStorage，表單保留供重試。


## 單位文件與表單、共用檔案庫（2026-11-18 更新）

從管理中心左側「單位文件與表單」→「新增文件」，設定名稱、說明、分類、版本、文件日期、公開範圍，並上傳或「選用既有檔案」。支援 PDF、PNG、JPEG，單檔 5 MB。單一單位管理員自動歸屬其管理單位；多單位管理員與高階管理員選擇授權範圍內單位，後端驗證後設定歸屬，不能以送入的 owner_unit_id 偽造。編輯器及列表顯示所屬單位、發布範圍與前台位置。

已發布文件可「發布更新」、「轉為草稿（停止公開）」或「下架」；歷史版本可載入後再儲存。單位管理員僅管理授權單位，醫研部總管理員與系統管理員可跨單位。所屬單位於建立後固定，附件必須與文件屬於同一單位。檔案名稱、大小、格式由伺服器的上傳紀錄取得。

對外文件出現在所屬單位子站「文件下載」，並保留全站「文件表單」總目錄。院內文件只出現在登入後的院內專區，下載及預覽均重新驗證工作階段。草稿／下架不顯示於這些清單。文件日期獨立於伺服器更新時間；編輯歷史文件不會自動把顯示日期改為今天。

「共用檔案庫」保存實體檔案與上傳中繼資料，顯示被哪些文件、消息或內容引用。獨立上傳不會自動建立或發布內容。文件、消息編輯器皆可選用同單位既有檔案，不需重傳。消息附件僅隨對應消息呈現，不自動混入文件下載區。移除關聯或下架不刪除實體檔案，也不破壞其他引用；若仍有其他公開內容引用，該檔案仍可匿名下載。後端阻止共用實體檔案同時被院內與對外已發布內容引用。原已公開的靜態範例無法直接改為私有，須更換私有儲存區檔案。

已依使用者確認移除六份初始示意文件及其 HTML 素材，現在初始下載清單僅保留人體生物資料庫九份原始 PDF。更新啟動會先備份並清理舊 state.json 的示範項目；已換上正式上傳檔案且不再標示示範的項目、歷史、授權及其他附件均保留。其他單位可自行上傳核定檔案並發布，未有文件時顯示空清單。Word／Excel 上傳尚未支援。

文件資料初始讀取 `data/documents.json`，首次管理儲存後保存於既有 DATA_DIRECTORY 的 documents 集合，沿用同一份資料卷、歷史與稽核。Git 更新不會覆蓋既有管理資料。前台使用 `content-page.html?page=downloads`，支援名稱／單位／說明搜尋、單位與類型篩選；預覽提供「另開檢視」，供不支援內嵌 PDF 的瀏覽器使用。

人體生物資料庫九份原始辦法及表單亦在「單位文件與表單」編輯，沿用原 PDF 而不重新上傳。原「辦法及表單」段落導向同一下載區。原始公開檔案於下架或換檔後仍保留舊網址，後台會提示這項差異；若要提供院內版本，須選擇私有上傳檔案。已確認日期保留，不明日期可留空，顯示「日期待確認」，不以來源查核日或更新時間代替。原始來源說明以唯讀資料保留，避免漏掉原站名稱與實際文件不同的提醒。詳見 [文件整合](biobank-documents-management.md)。

共用檔案庫同時列出「後台上傳」與「原始匯入檔案」。人體生物資料庫九份既有 PDF 標示原始檔名、原官網來源、來源查核日、來源說明及目前對應文件／狀態；按「前往文件管理」可進入文件清單維護。「原始來源，目前已換檔」代表文件已改用新檔案，舊 PDF 仍保留供原網址使用。清單直接讀取既有素材，不寫入上傳紀錄、不複製檔案。原始匯入與上傳項目皆依管理單位權限過濾。編輯器的「選用既有檔案」維持選用私有上傳檔案；既有原始文件從文件清單編輯即可，不需重傳。

## 單位摘要（縮版介紹）

在「單位資料」編輯既有 short_description，保留原簡介作為初始值，新增 1–100 字驗證與即時字數統計。此欄與完整介紹 full_description 分開。首頁、隸屬單位列表、部門介紹的單位卡片及搜尋結果共用單位資料；儲存後重新載入公開頁即可同步。單位管理員僅能修改授權單位，總管理員／系統管理員可跨單位。

功能沿用現有 FastAPI、院內登入、CSRF、私有 JSON 與實體檔案儲存，不以 localStorage 模擬正式權限。純靜態託管只有公開預設資料，無法執行管理寫入或院內下載；上線須部署既有後端、院方 SSO、HTTPS、持久資料卷與備份。病毒掃描、Word／Excel 上傳、大檔分段、物件儲存與多程序資料庫仍未提供。院內範圍目前代表所有已登入院內人員；管理權限另外依單位限制。

## 內容補齊版（2026-11-05）

研究資源總覽依研究業務、研究支援與研究網絡分組。新增部門主管／組織入口、研究團隊、核心實驗室、督導審查單位、諮詢人員及預約、課程與論文撰寫、約用助理資訊、院內外常用網站；消息附件可連至原官網。預約、E-Learning 與審查服務仍由原系統受理。

高階管理員從「一般內容頁」編輯文字；卡片與按鈕在進階內容的 groups → cards → actions 中維護，連結協定與欄位結構由後端驗證。單位管理員的權限範圍不變。全站搜尋新增一般內容頁、資源卡片與已發布公開文件；選取文件結果時會帶入文件清單的搜尋欄位。

舊後台資料會進行一次保留自訂欄位的升級，具體備份、合併與回復方式見 [內容更新與回復](content-refresh-rollback.md)。文件表單維持已確認格式與既有資料。
