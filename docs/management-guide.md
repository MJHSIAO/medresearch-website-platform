# 正式管理操作指南

## 初次授權

院方登入識別欄位已確認為 `sub`。維運人員於伺服器設定 `ADMIN_IDENTITY_CLAIM=sub`，並將第一位系統管理員實際回傳的 sub 填入 `SYSTEM_ADMIN_IDS`，重建容器後重新登入。真實名單不提交 Git。身分確認表格已關閉，院內專區只提供一般功能。

## 新增或停用人員

從院內專區進入管理中心，選「人員權限」→「新增授權」，輸入與院方欄位完全相同的識別值（若已確認該欄位為員編，即填員編），選角色。單位管理員需勾選一個以上單位。按「儲存授權」後生效；對方不需要先登入，之後登入取得相同識別值即套用授權。

既有授權選「調整／停用」，取消啟用可立即撤權。醫研部總管理員只能管理單位管理員；只有系統管理員能任命或停用高階角色。伺服器保留管理員只能由環境設定調整。沒有前端角色切換。

## 維護網站

管理中心採左側功能選單與工作台。左下顯示目前登入者的實際角色與授權單位，不提供角色切換；單位管理員只顯示獲授權單位，系統管理員可管理全部功能。工作台數量、最新消息與操作紀錄均讀取伺服器。手機以左上選單按鈕開啟功能，表格可橫向捲動。

「檔案與附件」列出目前角色可管理的實際伺服器上傳檔，顯示名稱、所屬單位與大小，可選單位後上傳。新版上傳會保存原檔名；舊檔優先使用消息附件名稱，無名稱則顯示原識別碼。此列表不包含初始靜態素材，也不自動刪除未引用檔案；消息仍可在表單內直接上傳並建立附件關聯。

- 單位資料：編輯介紹、宗旨、業務、目標及聯絡資訊；高階管理員可調整排序與進階結構欄位。
- 單位成員：新增或編輯公開成員，姓名、職稱及簡介由表單維護；成員摘要同步更新。
- 消息與發布：填標題、摘要與本文，分類使用選單；所屬單位由授權範圍選擇，既有消息不可自行移轉單位。按「儲存草稿」保存到伺服器，按「發布」才公開；已發布消息提供「發布更新」、「轉為草稿（停止公開）」及「下架」。顯示範圍及首頁推薦收在其他發布設定。
- 歷史版本：開啟編輯頁的「查看歷史版本」，展開檢視，選載入後再按儲存完成回復。其他人已更新時會拒絕覆蓋，須重新載入。
- 消息圖片與附件：直接在消息表單選檔上傳、預覽及移除，不需手填路徑。獨立「檔案與附件」入口可查看授權範圍內的伺服器檔案。只接受 PNG、JPEG、PDF，每個檔案 5 MB 上限。
- 首頁服務、一般內容頁、網站資訊與導覽：高階管理員使用對應入口修改。複合段落、附件、選單及資源連結保留在「進階內容欄位」JSON 編輯區，送出時後端驗證資料型別與連結協定。
- 共用外觀設定：僅系統管理員可修改共用主色及容器寬度（1100／1200／1320）。不允許上傳任意可執行模板或 JavaScript。
- 操作紀錄：依管理範圍查看最近 500 筆；伺服器保存完整紀錄。

## 儲存與維運界線

本版維持 JSON 儲存及單一程序架構，鎖定交易、原子替換與版本衝突控制避免同程序寫入互相覆蓋。禁止多 worker 或多實例共寫；重啟會清除登入 Session，但不清除正式內容及授權。

備份整個 DATA_DIRECTORY，還原前停止服務。正式資料卷不隨 Git 更新清空，不執行帶 `-v` 的 Compose down。磁碟權限與備份由維運管理。操作紀錄沒有對外刪除 API，但擁有磁碟權限者仍能修改；不宣稱不可竄改稽核。上傳檢查大小與檔頭，不等同防毒掃描。

寄信、外部防毒與多實例 Session Store 未在本次交付，線上洽詢維持停用。正式環境的院方登入回傳欄位及第一位管理員設定，仍須由維運確認。


## 將舊消息搬到伺服器

正式管理中心 `/admin` 的新增、儲存及發布都透過受保護 API 寫入私有 `DATA_DIRECTORY/state.json`；沒有 localStorage 寫入或離線保存。失敗會顯示錯誤，不會退回本機儲存。

舊版在瀏覽器保存的消息需另行匯入。在原本發布的電腦、瀏覽器及設定檔登入正式管理中心，選「匯入舊消息」→「預覽並匯入」→核對所屬單位→「匯入為伺服器草稿」。匯入只讀取原有 `medresearch_demo_news`，不修改或清除瀏覽器資料。

匯入保留原消息 ID 與日期，因此發布後原 news-detail 網址可繼續使用。匯入不會直接發布，請在消息編輯頁核對本文、顯示範圍及附件後發布。伺服器已有同 ID 時拒絕覆蓋；每次匯入仍驗證登入、CSRF 與單位權限。圖片／附件若當時只有瀏覽器預覽，需重新上傳。

換電腦、無痕模式或清除舊網站資料後，可能無法找到原消息。此時須由原瀏覽器備份或維運備份取回；僅憑標題或 URL 無法重建原文。只有原文已匯入並經伺服器儲存，才算完成復原。


## 簡化消息表單（2026-11-02）

新增／編輯消息改用專用表單，沒有圖片路徑手填欄位或進階 JSON。必填標題、摘要、本文，其餘以選擇或預設值處理；舊分類會保留在選單中。

發布、截止及活動日期均使用日曆。發布日期預設今天，未自行指定時以實際發布時間保存；截止日可留空。既有日期未改動時保留原時間及時區精度。日期是顯示資料，不提供預約發布。

消息表單直接多選 PNG、JPEG、PDF 上傳，每個檔案最多 5 MB；成功後顯示檔名、檢視連結，圖片可預覽。選檔即上傳至私有儲存區，儲存消息後才建立附件關聯；未發布內容不會公開附件。可從表單移除附件，儲存後生效；不會刪除伺服器檔案或其他消息的引用。

封面／列表預覽圖片選填，可從已上傳圖片按「用作列表預覽」設定，亦可選擇不使用。只有選擇預覽圖才顯示圖片說明；可提供簡短替代文字，未填時使用標題作基本說明。沒有封面仍可發布；PDF 不產生第一頁縮圖。

編輯及歷史回復會保留未變更的原始欄位、相關圖片、附件、分類與日期。已發布內容按「轉為草稿（停止公開）」會停止公開；若要更新公開內容，請按「發布更新」。保存失敗不寫入 localStorage，表單保留供重試。
