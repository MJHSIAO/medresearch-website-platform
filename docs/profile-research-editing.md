2026-11-25 本機修改及隔離預覽完成，使用者確認後已授權將本次功能與移除自動項目符號一併提交、推送 GitHub；未部署正式站。

## 欄位與資料保留

「研究成果／榮譽／專利」改為「榮譽」與「專利」，各上限 20000 字，空白區塊不公開顯示。九位初始資料已分類，未增加任何新事蹟：張至宏原欄位前三件專利移至專利，一般細胞治療等事績保留於完整介紹；廖秀蓉的專利 1–3 與前面的榮譽分開，其餘既有獎項、證照及訓練文字保留。

舊 `profile.achievements` 不刪除，後台可展開「既有合併欄位備份（唯讀）」核對。前台與搜尋使用新欄位，避免舊文字在編輯後重複顯示。既有姓名、職稱、照片、連結、順序、來源及其他單位資料不變；294 筆研究成果原文與 ID 不變。

更新後端啟動時，`profile-sections-2026-11-25` 一次性遷移先備份狀態：已分類或自訂的欄位不覆蓋，未被修改的舊初始文字依確定分類補上新欄位；自訂混合內容不推測分類，保留於完整介紹。如果合併超過介紹上限，保留為可編輯的「其他事績（既有內容）」及前台「其他事績」。刪除的人員不重新建立，舊版本及稽核不變；舊版歷史內容還原或舊客戶端傳回合併欄位時，也會先補為相容的新欄位，避免漏顯示。

## 研究成果與作者姓名

- 「論文與成果」統一改名「研究成果」。後端先依年份由新到舊排序，再搜尋／分頁；同年保留原順序，未填年份放最後。新增、改年份、重新載入均套用同一規則；不依引用文字猜測日期改寫舊資料。
- 在單位成員的「作者姓名寫法」每行填一種實際寫法，最多 20 種、每種 200 字，儲存成員後生效。既有公開英文全名作為初始值，中文姓名也會自動標示。縮寫不自行推測，可由管理員補入。
- 姓名比對不分英文大小寫、採完整姓名邊界，不將另一個較長姓名的片段誤加粗。自動加粗僅影響呈現，不改引用文字或手動格式；未知寫法仍可手動處理。同名作者需由管理員核對。

## 粗體、底線與貼上

新增／編輯單筆成果及批次內容皆提供格式按鈕。先選取文字，再按「粗體」「底線」或使用 Ctrl+B／Ctrl+U（macOS 為 Command）；再次套用可取消相應格式，也可「清除格式」。支援貼上 Word／網頁的粗體、底線及換行，其他字型、字級、顏色、連結、圖片或執行內容均不匯入。選取格式按鈕會顯示目前格式狀態。

每筆仍為 1–5000 字，批次每筆間空一行，最多 50 筆，每位最多 2000 筆；保留年份、類型及論文連結欄位。批次自引用文字辨識年份，可在儲存後修改。單次 API 仍受既有 1 MiB 限制，極大量格式內容可分批貼上；超限會回報，不截斷或部分儲存。一般文字編輯可超出字數後修正，儲存時驗證；貼上超出編輯器上限時保留原編輯內容並提示分批處理。

格式另存為 `runs: [{text, bold, underline}]`，`citation` 純文字繼續供搜尋與舊資料相容。伺服器逐項驗證格式、布林值及全文一致，前台只輸出轉義文字及固定的 strong／u 標籤，不儲存任意 HTML。純文字客戶端更新會清除舊手動格式，避免字文不一致；原純文字成果不需要重打。格式及文字仍使用既有私有 JSON、版本衝突檢查、版本歷史、稽核、CSRF 及逐次單位授權，沒有新增角色。
