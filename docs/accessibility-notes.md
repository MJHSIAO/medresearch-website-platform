# 無障礙與響應式設計備註

第一版以 WCAG 2.2 AA 為設計目標，而非宣稱已完成正式無障礙認證。

已納入的基礎設計包括：繁體中文語系、語意化區域、跳到主要內容連結、可見的 `:focus-visible`、鍵盤可操作的手機選單、Escape 關閉公開選單、表單 label、必填提示文字、非僅依顏色的錯誤訊息、圖片／視覺區塊文字替代、足夠的目標尺寸、減少動態偏好及手機表格橫向容器。

320px 版面以單欄、縮小邊距及按鈕滿寬避免整頁水平捲動；寬表格只在自身容器中水平捲動。正式上線前仍需搭配真實內容進行自動與人工無障礙測試，包括色彩對比、螢幕閱讀器、放大 200%／400%、重新排列、錯誤辨識與跨瀏覽器鍵盤操作。
