# 無障礙與響應式設計備註

## 2026-11-20 單位卡片圖示位置修正

人體生物資料庫成為最後一張卡片後，受到 units-directory.css 舊版桌機最後卡片 `align-items:center` 規則影響，圖示容器在跨列區域垂直置中。已移除被新版共用卡片取代的桌機特例，並明確設定圖示容器 `align-self:start`，不更換圖案或截斷內容，保留同列等高與底部按鈕對齊。

本機瀏覽器實測隸屬單位列表在 1141px 的八張圖示與各自標題頂端差均為 0px，卡片內距均為 31px，同列卡片等高且主要按鈕頂端一致。首頁及列表於 768px、320px 的八張圖示與標題差均為 0px，沒有整頁水平捲動（scrollWidth 分別為 753px、305px）。使用隔離預覽，未修改正式單位資料；與使用者已確認的簡稱及職稱修改一併提交、推送。

第一版以 WCAG 2.2 AA 為設計目標，而非宣稱已完成正式無障礙認證。

已納入的基礎設計包括：繁體中文語系、語意化區域、跳到主要內容連結、可見的 `:focus-visible`、鍵盤可操作的手機選單、Escape 關閉公開選單、表單 label、必填提示文字、非僅依顏色的錯誤訊息、圖片／視覺區塊文字替代、足夠的目標尺寸、減少動態偏好及手機表格橫向容器。

320px 版面以單欄、縮小邊距及按鈕滿寬避免整頁水平捲動；寬表格只在自身容器中水平捲動。 新聞圖片放大使用可聚焦按鈕與對話框，支援 Enter／Space 開啟、Escape 關閉、焦點返回觸發圖片，並保留另開新分頁查看原圖的入口。正式上線前仍需搭配真實內容進行自動與人工無障礙測試，包括色彩對比、螢幕閱讀器、放大 200%／400%、重新排列、錯誤辨識與跨瀏覽器鍵盤操作。
