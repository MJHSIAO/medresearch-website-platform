# 資訊架構

## 公開網站

```text
首頁
├─ 常用研究服務
│  ├─ 研究諮詢
│  ├─ 統計諮詢
│  ├─ 倫理與相關申請
│  ├─ 儀器設備
│  ├─ 課程活動
│  └─ 表單下載
├─ 最新消息
│  ├─ 列表與篩選
│  └─ 消息詳細頁
├─ 隸屬單位
│  ├─ 單位首頁共用版型
│  └─ 單位完整介紹共用版型
└─ 聯絡我們
```

首頁先回答「使用者想辦理什麼」，再呈現消息、亮點及單位；不把組織名稱大量堆疊成主要入口。

## 行政後台 Demo

```text
後台首頁
├─ 新增／管理最新消息
├─ 修改單位介紹、服務、成員及聯絡資訊
├─ 圖片與附件瀏覽器端預覽
├─ 預覽單位網站
└─ 操作紀錄
```

醫研部總管理員另看到首頁推薦、單位排序與跨單位管理示意；系統管理員看到版型、帳號角色與系統設定示意。這些入口不代表正式權限已完成。

## URL 與共用版型

- `unit.html?unit={slug}`：單位首頁。
- `unit-about.html?unit={slug}`：一般單位完整介紹。
- `ai-center/index.html`：人工智慧中心官網第一版入口。
- `content-page.html?page={id}`：一般內容頁。
- `news-detail.html?id={id}`：消息詳細頁。

跨單位導覽規則：醫學研究部主站的單位卡片以新分頁開啟；人工智慧中心子站前往醫學研究部或隸屬單位列表時也以新分頁開啟，單一網站內的主選單仍採同頁導覽。

新增單位或一般內容時，優先新增資料而不是複製 HTML。
