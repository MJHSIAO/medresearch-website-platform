## 新增的升級規則

`confirmed-live-profile-sections-2026-11-25` 在既有欄位升級之後執行：

1. 先備份完整私有 `state.json` 為 `state.before-confirmed-live-profile-sections-2026-11-25.json`，既有備份不覆寫。
2. 只核對三筆指定成員的原合併文字 SHA256，並要求完整介紹仍等於原合併文字、榮譽及專利皆空白。
3. 從該筆正在使用的伺服器文字搬移，不讀取或複製 `data/people.json` 的初始介紹。廖秀蓉依已確認的原分隔線及 Patent 標題分開；原裝飾分隔線仍保留於合併備份。
4. 原合併文字保留，並記錄修改前後歷史版本；姓名、職稱、其他介紹欄位、聯絡、來源、排序、單位、授權、附件、研究成果及既有稽核不變。
5. 已正確拆分的正式資料不重寫；文字哪怕只改一字、已有新欄位內容或另有介紹，都不套用此修復。重啟也不重新執行或復活舊資料。新安裝不建立任何額外人物。

SHA256 僅用來限定已確認的資料版本，並非一般自動分類器。未確認的新版本仍由管理員依實際內容分類。正式站本次已透過管理中心修正；Git 推送本身不會部署程式，也不會再次變更目前正式內容。
